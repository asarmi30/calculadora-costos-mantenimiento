# Calculadora de costos de mantenimiento

Aplicación web sencilla, hecha con HTML, CSS y JavaScript, que calcula el costo de actividades de mantenimiento de software según su categoría (correctivo, adaptativo, perfectivo y preventivo). Es el proyecto de la Actividad 4 del módulo Mantenimiento de Software (Corporación Universitaria Iberoamericana), con el que se practica el versionamiento colaborativo con Git y GitHub. Se relaciona con la Actividad 2, donde se estimaron los costos de mantenimiento de un producto SaaS.

## Cómo ejecutarla

No requiere instalación. Descargue o clone el repositorio y abra `index.html` en el navegador.

## Estructura

- `index.html`: página principal.
- `app.js`: lógica de cálculo y lista de actividades.
- `style.css`: estilos.
- `docs/historias-de-usuario.md`: historias de usuario del proyecto.

## Flujo de ramas

- `main`: versión estable e integrada.
- `develop`: desarrollo, donde se reúnen las funcionalidades terminadas.
- `test`: pruebas antes de pasar a `main`.
- `feature/HUx-nombre`: una rama por historia de usuario.

## Convención de commits

Los mensajes indican el tipo de cambio y la historia: `fix(HU1): ...`, `refactor(HU2): ...`, `feat(HU3): ...`, `feat(HU4): ...`, `feat(HU5): ...`.
